# PWA-версия «Сечения многогранников» (для iPhone/iPad и любого телефона)

Эта папка — готовый к публикации сайт из 9 файлов. После публикации
его можно «установить» на iPhone: он появится на рабочем столе как обычное
приложение, запускается на весь экран и **после первой загрузки работает
без интернета**. Никакой телеметрии и рекламы: service worker кэширует
только файлы из этой папки, внешних ссылок в коде ноль.

## Как опубликовать (бесплатно, ~10 минут, нужен аккаунт GitHub)

1. Зарегистрируйся на https://github.com (если ещё нет аккаунта).
2. Нажми **+ → New repository**. Имя — например `sections-app`
   (от него зависит адрес!). Остальное не трогай, кнопка **Create repository**.
3. На странице репозитория нажми ссылку **uploading an existing file**.
4. Перетащи туда ВСЕ файлы из этой папки `pwa` (index.html, sw.js,
   manifest.webmanifest, иконки, .nojekyll) и нажми **Commit changes**.
   ⚠ Перетаскивай сами файлы, НЕ папку pwa целиком — файлы должны лежать
   В КОРНЕ репозитория, иначе сайт не найдётся.
5. Зайди в **Settings → Pages** (слева в меню настроек репозитория).
   В разделе «Build and deployment»: Source = **Deploy from a branch**,
   Branch = **main**, папка **/ (root)**, нажми **Save**.
6. Подожди 1–2 минуты и обнови страницу Settings → Pages: сверху появится
   адрес вида `https://ТВОЙ-НИК.github.io/sections-app/`. Это и есть
   ссылка на приложение — её можно открывать на любом телефоне.

## Как установить на iPhone

1. Открой ссылку в **Safari** (именно в Safari, не в Chrome — только он
   умеет «На экран Домой»).
2. Нажми кнопку **«Поделиться»** (квадратик со стрелкой вверх, внизу).
3. Выбери **«На экран "Домой"»** → **«Добавить»**.
4. На рабочем столе появится иконка с кубом и сечением — запускай как
   обычное приложение.
5. Проверь офлайн: включи авиарежим и открой приложение — должно работать.

⚠ Интернет нужен только для ПЕРВОГО открытия (service worker скачает и
сохранит файлы). Если приложение однажды перестанет работать офлайн
(iPhone редко, но чистит кэш при нехватке места) — просто открой его
один раз при интернете, всё закэшируется заново.

## Как установить на Android

Открой ту же ссылку в Chrome → появится кнопка «Установить приложение»
или меню → «Добавить на главный экран». (Но у нас уже есть APK — он
полностью заменяет PWA на Android.)

## Как пересобрать (для разработчика)

```
py -3 tools/build_mobile.py    # если менялся mobile/src/*.js
py -3 tools/build_pwa.py       # пересобирает эту папку pwa/
node mobile/tools/check_pwa.js # проверка PWA (манифест, sw, иконки)
```

Кэш service worker версионируется хэшем содержимого: после пересборки
телефон при первом же открытии онлайн подхватит новую версию сам.
